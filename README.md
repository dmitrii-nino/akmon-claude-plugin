# Akmon for Claude

Akmon connector and skill for Claude. Ask Claude to humanize or paraphrase text and it sends the text to Akmon and returns the result.

Install in Claude Code:

    /plugin marketplace add dmitrii-nino/akmon-claude-plugin
    /plugin install akmon@akmon

Connector only:

    claude mcp add --transport http akmon https://mcp.akmon.app/mcp

Sign in to Akmon when asked. More: https://akmon.app/support/#claude-chatgpt

Privacy: https://akmon.app/privacy/
